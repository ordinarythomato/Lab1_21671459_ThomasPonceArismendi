# Pokemon TCG Simulator with Scheme (Incomplete)

(English)
Repository made for Laboratory 1 from USACH Programming Paradigms course, 1st semester 2026.
Lab's main task was creating a Pokemon TCG Simulator with Scheme. In Scheme I learned to create and manage complex functions for the game, to catalogue Pokemon attributes and to connect both to a game draft.
NOTE: The presented functions work well according to the assignment's purpose, but in that period I couldn't get to finish all the project due to its deadline. Although, this project was my first insight to the Scheme language.
